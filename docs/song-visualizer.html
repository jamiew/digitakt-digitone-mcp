Live visualizer design

A truthful live view combines transport events with cached pattern dumps. It does not claim to mirror the Digitakt OLED.

1 · Observe

Capture MIDI Start, Stop, Continue, Clock, Song Position, Program Change, notes, and CC. Summarize high-rate clock traffic instead of returning every message.

Digitakt MIDI
  ├─ transport → live position
  ├─ program   → active pattern
  └─ notes/CC  → activity + automation

2 · Cache

Pull the 31 KB pattern-plus-kit dump only at stable boundaries. Polling a full dump on every tick would waste bandwidth and disturb timing.

on connect       pull selected pattern
on pattern change mark cache stale
on stop/manual   refresh stale pattern

3 · Render

Merge the event stream and cache into the horizontal lanes already used here. Show observed state, cached state, and inferred state with separate labels.

event stream + pattern cache
            ↓
bar / step / track activity
conditions / locks / song rows

4 · Control safely

Opening the view must not write. Put pattern edits, CC moves, and transport controls behind explicit actions with readback and undo data.

VIEW  read-only by default
EDIT  preview diff → apply → read back
UNDO  restore captured pattern dump

Sequencing tricks

The arrangement ideas expressed as small, reusable recipes.

Fourth-pass snare roll

Retrig belongs to each trig. Length ends the burst; a later normal hit can interrupt it.

Passes 1–3
49  4:4      → false
53  NOT PRE  → normal snare
60  4:4      → false
61  NOT PRE  → normal snare

Pass 4
49  4:4      → 1/8 roll
53  NOT PRE  → skipped
57  4:4      → 1/16 roll
60  4:4      → 1/32 roll
61  NOT PRE  → skipped

A/B phrase on one pattern

P2a and P2b are two passes of P2. Paired MIDI tracks can alternate parts on one Digitone voice.

P2[128] = P2a + P2b

T9   phrase A  condition 1:2
T10  phrase B  condition 2:2

Both → same Digitone channel

Open-hat choke

Use one monophonic sample track rather than layering open and closed hats on separate tracks.

O·······O·······O···
└ tail ─┘
          new trig chokes old tail

P5 uses loaded sample slot 7.

One-bar transition

A 16-step transition can replace the eighth bar or add an intentional ninth bar.

Keep 8 bars:
P4 row 112 + P8 row 16 = 128
7 bars     + 1 bar      = 8

Odd-bar tension:
P4 row 128 + P8 row 16 = 9 bars

Build without a riser

Use note and CC behavior to create lift, then explicitly reset on the drop.

filter cutoff    34 → 118
resonance        18 → 82
amp release      short → long
note spacing     wide → tight

DROP: reset all values

One voice at a time

Foreground detail moves between parts. Supporting tracks can continue, but they stop making speeches.

bar 1  bass moves, lead rests
bar 2  lead answers, bass holds
bar 3  groove returns
bar 4  drums drop, fill owns turn
